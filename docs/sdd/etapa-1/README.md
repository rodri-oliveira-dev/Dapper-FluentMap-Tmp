# Etapa 1

## Objetivo

Corrigir e fortalecer pontos centrais da resolucao de mapeamentos do `Dapper.FluentMap`, preservando a API publica e o comportamento existente sempre que possivel.

## Entregas Previstas

1. ReflectionHelper
2. Composicao de mappings
3. Testes de integracao com Dapper
4. MappingRegistry e cache

## Ordem Das Entregas

As entregas devem ser executadas na ordem acima, pois cada uma produz contexto e decisoes que podem afetar a proxima.

## Leitura Obrigatoria

Antes de iniciar proximas tarefas desta etapa, leia todos os arquivos `.md` diretamente relacionados em `docs/sdd/etapa-1/`, principalmente este `README.md`, `status.md`, `decisions.md` e relatorios de entregas anteriores.

## Escopo

O escopo atual esta concentrado no projeto principal `Dapper.FluentMap`.

`Dapper.FluentMap.Dommel` esta fora do escopo funcional desta etapa, salvo se uma mudanca comprovada no core exigir adaptacao explicita.
